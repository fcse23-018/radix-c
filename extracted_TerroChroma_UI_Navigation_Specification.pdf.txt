This document defines the complete visual language, navigation structure, screen hierarchy, interaction patterns,
and native subscription integration for the TerroChroma mobile application. The design prioritizes outdoor
readability, one-handed field use, and a warm soil-and-vegetation color system that reinforces the product’s
connection to land and regenerative agriculture.

3. Screen-by-Screen Interface Vision
3.1 Home / Dashboard
Warm cream background. Top app bar in Soil Brown with subtle green accent line. Large “Last Sample” card
shows SOC %, SOM %, confidence interval, and a thumbnail of the processed soil region. A horizontal stats row
displays samples taken today / this week and average SOC. Below sits a scrollable list of recent sample cards
(swipeable). The center FAB (Leaf Green) is always present for new capture.
  Header shows current location context + offline/online indicator
 Last Sample card uses soft elevation and Warm Beige surface
 Empty state gently prompts the user to take their first sample
3.2 Capture – Guided Viewfinder (Core Experience)
Full-screen camera viewfinder with live overlays. The design is deliberately minimal so the soil and calibration card
remain the visual focus.
  Real-time alignment guides highlight ArUco / AprilTag corners on the calibration card
 Digital spirit-level bubble (IMU-driven) turns green when pitch/roll ≤ 10°
 Ambient light quality meter warns if lighting is too harsh, dim, or uneven
 Status chips: “Level OK”, “Light OK”, “Card Detected” appear only when relevant
 Large circular shutter button (Leaf Green) becomes active only when all gates pass
 Capture sequence: Card Alignment → Stability Check → RAW Lock → Local Inference → Result
3.3 Result Overlay / Bottom Sheet
After inference completes (target < 2 s), a bottom sheet rises with generous spacing:
  Large SOC % number (primary) and SOM % (secondary)
 Carbon stock (Mg C/ha) when bulk density is available
 Confidence / uncertainty band displayed as a clear visual range
 Thumbnail of the segmented soil ROI + key color metrics (L*, Munsell Value)
 Primary actions: Save & Tag  Retake  Add Note / Moisture
 Secondary: Share / Export this sample
3.4 Map
Full interactive map using platform map SDKs. Sample pins are color-coded by SOC range using the green–brown
scale (low carbon = lighter soil brown, high carbon = deeper leaf green). Tapping a pin opens a compact bottom
sheet with summary metrics and a jump-to-detail action. Filters (date, SOC threshold, sync status) sit in a
collapsible top bar.
3.5 Library / History
Searchable and filterable list (or optional grid) of all samples. Each card shows thumbnail, date/location, SOC
value, and sync status badge. Multi-select mode enables bulk export (GeoJSON / KML / CSV) or deletion. Detail
view expands to full metrics, feature vector summary, provenance hash, map snippet, notes, and image gallery.
3.6 Settings
Grouped into clear sections: Account & Subscription, Calibration Cards, Models & Regional Overlays, Units &
Display, Offline Sync & Storage, Hardware Diagnostics (camera lock test, IMU, BLE spectrometer pairing), and
About / Legal. Subscription management deep-links to the native store subscription screen.

5. Native-Only Subscription Model
Subscriptions are implemented exclusively with platform-native billing systems: Google Play Billing Library on
Android and StoreKit 2 on iOS. No third-party subscription management platforms are used.

5.2 Price & Offer Management
All prices, free trials, introductory offers, and promotional codes are managed directly inside Google Play Console
and App Store Connect. Changing a price or trial length does not require an app update; the stores push the new
commercial terms to the billing libraries. The app only needs to query the current product details at runtime.
5.3 In-App Experience
  Soft paywall appears after the user has taken a small number of free samples (value-first)
 Paywall screen uses the same soil-green visual language; clear yearly savings callout
 “Restore Purchases” button is always visible and easy to find
 Active subscription status is checked on launch and before gated actions
 “Manage Subscription” deep-links to the native store subscription management UI
 Entitlement checks are performed locally after the billing library confirms status
5.4 Technical Notes (Native Only)
Android: Use Google Play Billing Library 7+ with a clear ProductDetails → purchase flow and
acknowledge/consume handling. iOS: Use StoreKit 2 (Product, Transaction, RenewalInfo) with StoreKit Testing in
Xcode for development. Both platforms require server-side receipt validation for production security; a lightweight
backend endpoint is still recommended even with a pure native client approach.

6. Core Design Principles
 Outdoor First — High contrast, large type, no large pure-white surfaces. Status colors remain distinguishable
under bright sun.
 One Primary Action — Every screen has one obvious next step. Capture is always one tap away via the
center FAB.
 Error Prevention — Capture is blocked until tilt, light, and card detection are satisfied. Messages are short
and non-technical.
 Offline by Default — All core flows work without network. Sync status is visible but never blocking.
 Progressive Disclosure — Field technicians see a simple path. Agronomists can expand to raw L*a*b*,
GLCM, model ID, and provenance.
 Warm & Grounded — Soil browns and living greens reinforce the product’s connection to land. Avoid cold
greys and pure blacks.
 Thumb-Friendly — Critical controls sit in the lower half of the screen for comfortable one-handed use in the
field.
