1. Executive Overview & System Scope
This Software Requirements Specification (SRS) defines the operational, mathematical, and algorithmic
requirements for the Smartphone-Based Soil Organic Carbon (SOC) System. The platform
transforms commodity mobile devices into point-of-use optical soil analyzers. By capturing uncompressed
camera sensor frames alongside a physical calibration target, the system isolates humic chromophore
absorption in visible light (400–700 nm) and pairs it with spatial environmental covariates to deliver
rapid, laboratory-grade SOC and SOM estimations.

4. Functional Requirements Specification
The software system must enforce hardware control, real-time image analytics, spatial metadata
acquisition, and machine learning inference according to the functional modules specified below.
Module 1: Optical Capture & Hardware Control
FR-1.1 (Camera Parameter Lock): The system shall programmatically lock ISO, shutter speed, manual
focus distance, and turn off hardware auto-white-balance.
FR-1.2 (Bayer RAW Capture): The mobile application shall store uncompressed RAW (Android DNG or
iOS Bayer RAW) sensor frames directly alongside compressed JPEG assets.
FR-1.3 (Inclinometer Gate): Image acquisition shall be inhibited if IMU pitch/roll sensors measure an
off-axis tilt angle exceeding 10° from normal.

6. Non-Functional System Requirements
NFR-1 (Inference Latency): On-device Machine Learning inference (SOC % prediction from a single captured
sample) shall execute in less than 2.0 seconds on mid-tier mobile hardware.
NFR-2 (Offline Cache Capacity): The mobile app shall securely cache up to 1,000 un-synced field samples
locally in an encrypted database (SQLite/Room) during extended offline field operations.
NFR-3 (Data Cryptography): All local database entries, GPS tags, and raw image matrices must be encrypted
at rest using AES-256 standard encryption.
NFR-4 (Provenance Integrity): Every generated SOC prediction must attach a cryptographic hash of the raw
image, camera exposure parameters, and model identifier for auditability.

7. Domain Science & Soil Physics Fundamentals
Soil Organic Carbon (SOC) is the primary component of Soil Organic Matter (SOM). Organic humic
fractions (humic and fulvic acids) act as dark chromophores in visible spectrum wavelengths. As SOC
concentration increases, total spectral reflectance decreases sharply in the 400–700 nm range.
Universal Carbon Conversion Standard (Van Bemmelen Factor):
SOM (%) = SOC (%) × 1.724
Where SOC represents elemental organic carbon determined via dry combustion (ISO 10694).

9. Data Pipeline & Machine Learning Strategy
The analytical core utilizes a multi-stage feature extraction engine. Device-independent CIE L*a*b*
coordinates isolate lightness (L*) as the primary SOC proxy. Texture features are extracted using Gray-
Level Co-occurrence Matrices (GLCM), while External Parameter Orthogonalization (EPO) mitigates soil
moisture interference.
Feature Vector Engineering Array:
Vector X = [ L*, a*, b*, Munsell_Value, GLCM_Contrast, GLCM_Energy, NDVI_Sat,
Clay_Content ]
